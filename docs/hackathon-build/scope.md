# VINRelease Scope

VINRelease is a CALL-E-powered exception desk for dealership vehicle titles that are stuck after ordinary digital workflows stop providing an answer.

## P0

- Seed or create one overdue title case with governed external contacts.
- Preview a purpose-bounded call and require explicit authorization.
- Execute CALL-E from the server with a strict recipient result schema and idempotency key.
- Persist the provider call ID, status, evidence, result, and transcript reference.
- Convert validated results into deterministic case transitions.
- Chain the auction result to an approved lienholder call.
- Stop on ambiguity, unsupported questions, credentials, legal decisions, or financial decisions.
- Offer a safe demo mode that can never dial.
- Present the resolution history as a clear operations timeline.

P1 and P2 items in the source specification are excluded until this path is complete.

## Wow moment

A judge watches one stuck vehicle move from an unknown blocker to a verified lien-release reference through two governed calls, while the product visibly refuses to overclaim that the physical title has arrived.
